# Практикум педагога · От фильма к действию

Изолированный прототип нового пользовательского пути подготовки педагога к киноуроку «Великий».

## Цель
Сделать быстрый маршрут для педагога с ограниченным временем, не теряя методическую глубину.

## Архитектура
- слой 1: быстрый путь к реальному проведению занятия;
- слой 2: методическая глубина по запросу в контексте конкретного шага;
- восемь этапов проекта сохранены;
- существующие сайты «Великий» и «Мандарин» не изменяются.

## Публикация
Публичная версия развёрнута только в новом каталоге GitHub Pages:
`/praktikum-pedagoga/`

Рабочая ветка: `praktikum-v1`.
